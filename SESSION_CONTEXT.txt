  - Stack: Angular 22, Node + Express 5 + TypeScript, PostgreSQL 18,
    Prisma 7 (not 8 RC). Express over NestJS (shows the request flow).

    service}; server.ts (start) / app.ts (middleware) / routes.ts (one line
    per feature). Only services touch Prisma; only controllers touch req/res.

    404 missing, 201 created. DB column limits mirror the API limits.
  - Settings via config/env.ts (DATABASE_URL required; PORT 3000;
    CORS_ORIGIN default http://localhost:4200).
  - snake_case in DB, camelCase in code via @map/@@map.
  - Structure changes = edit schema → migrate dev → generate (Prisma 7 does
    NOT generate automatically). Never change structure in pgAdmin.
  - Seed data in code (prisma/seed.ts), safe to re-run.
  - Dates stored as real DATE columns; Angular formats them.
  - Frontend: httpResource for reading; HttpClient.post for the contact form
    (a one-off action); Reactive Forms; one component per section; OnPush;
    signals; shared CSS helpers in styles.scss (.btn, .lift, .arrow, .pop,
    .reveal, .stagger, .mono-label).
  - Contact: B now (save to DB), C (email via Resend) at deployment.
  - Hosting: Vercel (Hobby) for BOTH web and API (two projects from one repo,
    Root Directory web / api) + Neon Postgres from the Vercel Marketplace.
    Migrations run automatically in "vercel-build"; seed is run by hand.
    Separate domains → CORS_ORIGIN must equal the live website address.
  - API stays on TypeScript 6 (TS7 broke Vercel's transpiler).
  - Design: "J · Light & Calm" (light page, navy text, apricot accent,
    Nunito). Phone number never shown. No availability badge. Favicon is a
    code icon, not the user's photo.

F. PROBLEMS, FAILED ATTEMPTS, LESSONS
==============================================================================
  - Node 20 shadowed nvm → uninstall standalone Node; restart VS Code.
  - "relation already exists" → query ran twice. UPDATE 0 → row was deleted.
  - CORS: middleware must come BEFORE routes (and before listen).
  - "Cannot find name 'process'" → "types":["node"] + include config file.
  - prisma.<model> missing → run `npx prisma generate` (+ restart TS server).
  - /** */ comments invalid in schema.prisma → use // or ///.
  - PowerShell ">" writes UTF-16 → use Git Bash.
  - Postman 404 on /api/contact → method was GET; must be POST.
  - pgAdmin doesn't show new tables until Tables → Refresh.
  - git add . inside web/ only stages web → commit from the root.
  - First Prisma attempt too fast → revert and redo slowly.
  - "CORS error" on EVERY request with empty response headers = the local
    API wasn't running (not a CORS setting). Check localhost:3000/api/skills.
  - Secrets leaked in screenshots twice (.env open in VS Code) → rotate the
    key, close .env before screenshots.
  - Vercel/Neon lessons: Neon connect dialog defaults the env prefix to
    STORAGE → change to DATABASE. First API build fails before Neon is
    connected (expected). "Redeploy" on an OLD deployment page rebuilds that
    OLD commit — use the Deployments list / latest row. Angular output is in
    dist/web/browser (needs vercel.json). Settings → "Environments" is not
    "Environment Variables" (the latter is in the project's main menu).
    Env-var changes need a redeploy. Explain Neon simply: "Postgres in the
    cloud".
  - Claude-side tooling: type-check api with
    `node ../web/node_modules/typescript/bin/tsc -p tsconfig.json` (TS 7 is a
    Windows binary); web with `node node_modules/@angular/compiler-cli/
    bundles/src/bin/ngc.js -p tsconfig.app.json --noEmit` (+ tsconfig.spec.json);
    SCSS with `node node_modules/sass/sass.js --no-source-map <file>`.
    `ng build`/vitest can't run there. Prisma CLI can't run there (engine
    download blocked). Copying node_modules over the mount is very slow —
    symlink instead. File deletion needs a permission prompt.
